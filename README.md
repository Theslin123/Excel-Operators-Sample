# Excel-Operators-Sample
Practiced Excel logical, text, mathematical, and comparison operators using employee data.
# Topics Covered
* Logical operators: AND, OR
* Conditional function: IF
* Text concatenation using &
* Mathematical operators for salary calculations
* Comparison operators to check conditions and eligibility
# Learning Outcomes
Learned to apply multiple conditions, combine text values, calculate salary increments and performance allowances, and perform employee eligibility checks using Excel formulas.
